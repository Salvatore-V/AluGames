# 🎮 AluGames

Aplicação web desenvolvida durante os cursos de lógica de programação e JavaScript da Alura[cite: 6]. O projeto simula uma plataforma de aluguel de jogos de tabuleiro, permitindo que o usuário visualize um catálogo de títulos e altere dinamicamente o status de aluguel de cada jogo (Alugado / Devolver).

---

## 🚀 Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla)**

---

## 🛠️ Funcionalidades

* **Catálogo de Jogos**: Exibição de diferentes jogos disponíveis para locação com imagens customizadas.
* **Alternância de Status**: Botão interativo que altera o estado do jogo entre "Alugar" (disponível) e "Devolver" (alugado), modificando o estilo visual do botão e da tag correspondente.
* **Manipulação do DOM**: Atualização dinâmica da interface conforme as interações do usuário.
